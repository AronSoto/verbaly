# v0.1.0 — Primer release público
Fecha: 2026-07-02 · Estado: publicado (`verbaly` en npm; `@verbaly/compiler` + `@verbaly/vite` pendientes de publicar)

## Resumen
Set mínimo usable de i18n compilador+runtime: escribes texto natural, un plugin de build extrae keys estables, tipos y catálogos por locale; runtime diminuto y tree-shakeable. 98 tests, build/typecheck/lint en verde.

## Por paquete

### verbaly (core) — 43 tests · ~3.12KB gzip · cero deps · dual ESM+CJS
- Formato de mensaje propio con `Intl` por debajo: `{name}` auto-format, `{v:fmt/arg}` (number/integer/percent/currency/date/time + custom), `{v | one: … | other: # …}` unifica plural (Intl.PluralRules) y select/género. Escapes `{{ }} || ##`.
- Locale store reactivo (subscribe/notify), fallback chain + narrowing BCP-47 (`es-MX`→`es`).
- `t` dual: `t(key, params)` type-safe (FlatKeys) + tagged template `t\`…\``.
- `addMessages` (merge lazy), `has`, `onMissing`, warn-once.
- DOM interpreter `bindDom`: `data-verbaly` + `data-verbaly-args`, re-render en cambio de locale, `MutationObserver`, `textContent` only (sin XSS), traducción de atributos vía `data-verbaly-attr` (bloquea `on*`), unbind limpio.
- Params requeridos a nivel de tipos (`ParamNames`/`TArgs`, template literal types). `Verbaly<D>`/`TFunction<D>`.
- Getter `version` (contador de cambios) para reactividad de frameworks.

### @verbaly/compiler — 38 tests · ESM-only
- Extracción AST (@babel/parser 8), keys estables sha256 base64url 8 chars, transform con magic-string + sourcemaps.
- Catálogos JSON planos con sync automático; `check` de faltantes y keys desconocidas; codegen de `virtual:verbaly` (code-split por locale) + `verbaly.d.ts` tipado.
- CLI `verbaly extract | check | --prune`; config file `verbaly.config.{js,mjs,json}`.

### @verbaly/vite — 7 tests · ESM-only · Vite 7/8
- Virtual modules, extracción en vivo (escritura debounced + invalidación HMR), `verbaly.d.ts` auto, **build bloqueado si faltan traducciones**.

### @verbaly/react (4 tests) · @verbaly/vue (6 tests)
- react: `VerbalyProvider` + `useVerbaly`/`useT`/`useLocale` (`useSyncExternalStore`, React 18/19, dual ESM+CJS).
- vue: `verbalyPlugin` + composables `useT`/`useLocale` (ref + `onScopeDispose`, Vue ^3.4).

## Breaking changes
- Ninguno (primer release).

## API nueva / firmas
- `createVerbaly(options): Verbaly` — instancia (locale store, `t`, `addMessages`, `has`, `bindDom`, `version`).
- `t(key, params)` y `` t`texto ${x}` `` (tagged template pre-compilador).
- `bindDom(root?, options?)` — intérprete de DOM.
- Formatters custom: `(value, locale, arg?) => string`.
- CLI: `verbaly extract`, `verbaly check`, `verbaly extract --prune`.
- Plugin: `import verbaly from '@verbaly/vite'`.
