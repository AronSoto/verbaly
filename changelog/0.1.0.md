# v0.1.0 — First public release
Date: 2026-07-02 · Status: published (`verbaly` on npm; `@verbaly/compiler` + `@verbaly/vite` pending publish)

## Summary
Minimal usable set of compiler + runtime i18n: write natural text, a build plugin extracts stable keys, types, and per-locale catalogs; tiny, tree-shakeable runtime. 98 tests, build/typecheck/lint green.

## Per package

### verbaly (core) — 43 tests · ~3.12KB gzip · zero deps · dual ESM+CJS
- Own message format backed by `Intl`: `{name}` auto-format, `{v:fmt/arg}` (number/integer/percent/currency/date/time + custom), `{v | one: … | other: # …}` unifying plural (Intl.PluralRules) and select/gender. Escapes `{{ }} || ##`.
- Reactive locale store (subscribe/notify), fallback chain + BCP-47 narrowing (`es-MX`→`es`).
- Dual `t`: `t(key, params)` type-safe (FlatKeys) + tagged template `t\`…\``.
- `addMessages` (lazy merge), `has`, `onMissing`, warn-once.
- DOM interpreter `bindDom`: `data-verbaly` + `data-verbaly-args`, re-render on locale change, `MutationObserver`, `textContent` only (no XSS), attribute translation via `data-verbaly-attr` (blocks `on*`), clean unbind.
- Type-level required params (`ParamNames`/`TArgs`, template literal types). `Verbaly<D>`/`TFunction<D>`.
- `version` getter (change counter) for framework reactivity.

### @verbaly/compiler — 38 tests · ESM-only
- AST extraction (@babel/parser 8), stable keys sha256 base64url 8 chars, transform via magic-string + sourcemaps.
- Flat JSON catalogs with automatic sync; `check` for missing and unknown keys; codegen of `virtual:verbaly` (per-locale code-split) + typed `verbaly.d.ts`.
- CLI `verbaly extract | check | --prune`; config file `verbaly.config.{js,mjs,json}`.

### @verbaly/vite — 7 tests · ESM-only · Vite 7/8
- Virtual modules, live extraction (debounced writes + HMR invalidation), auto `verbaly.d.ts`, **build blocked when translations are missing**.

### @verbaly/react (4 tests) · @verbaly/vue (6 tests)
- react: `VerbalyProvider` + `useVerbaly`/`useT`/`useLocale` (`useSyncExternalStore`, React 18/19, dual ESM+CJS).
- vue: `verbalyPlugin` + `useT`/`useLocale` composables (ref + `onScopeDispose`, Vue ^3.4).

## Breaking changes
- None (first release).

## New API / signatures
- `createVerbaly(options): Verbaly` — instance (locale store, `t`, `addMessages`, `has`, `bindDom`, `version`).
- `t(key, params)` and `` t`text ${x}` `` (pre-compiler tagged template).
- `bindDom(root?, options?)` — DOM interpreter.
- Custom formatters: `(value, locale, arg?) => string`.
- CLI: `verbaly extract`, `verbaly check`, `verbaly extract --prune`.
- Plugin: `import verbaly from '@verbaly/vite'`.
